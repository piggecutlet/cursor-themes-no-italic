# Cursor Themes No Italic

## Installation

### Windows (Command Prompt)

```
cd "%LOCALAPPDATA%\Programs\cursor\resources\app\extensions" && git clone https://github.com/piggecutlet/cursor-themes-no-italic.git themes-cursor-no-italic
```

### PowerShell

```pwsh
cd "$env:LOCALAPPDATA\Programs\Microsoft VS Code\*\resources\app\extensions" && git clone https://github.com/piggecutlet/cursor-themes-no-italic.git themes-cursor-no-italic
```

### macOS (bash / zsh)

```
cd /Applications/Visual Studio Code.app/Contents/Resources/app/extensions && git clone https://github.com/piggecutlet/cursor-themes-no-italic.git themes-cursor-no-italic

cd /Applications/Cursor.app/Contents/Resources/app/extensions && git clone https://github.com/piggecutlet/cursor-themes-no-italic.git themes-cursor-no-italic
```
